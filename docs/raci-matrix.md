# Матрица RACI

Матрица RACI определяет участие членов команды в задачах проекта:

- **R (Responsible)** — выполняет работу;
- **A (Accountable)** — несёт итоговую ответственность за результат;
- **C (Consulted)** — консультирует и участвует в обсуждении;
- **I (Informed)** — получает информацию о ходе и результате.
