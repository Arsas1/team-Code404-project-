# Визуальный стиль CODE 404

## Направление

Тёмный технологичный стиль с фиолетовыми и синими акцентами. Визуальные материалы помогают быстро отличать проектную навигацию от содержания отчётов.

## Файлы

- `assets/images/code404-hero.png` — главный баннер README.
- `assets/code404-mark.svg` — знак команды для использования в документах и презентациях.
- `assets/images/product-flow.svg` — схема предполагаемого сценария работы продукта.

## Правила

1. Использовать относительные пути к изображениям из репозитория.
2. Добавлять осмысленный альтернативный текст (`alt`).
3. Не выдавать концепт-макеты за скриншоты реализованного приложения.
4. Сохранять единый стиль заголовков и навигационных ссылок.
5. Для новых отчётов использовать `report-template.md`.
