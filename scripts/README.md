# Скрипты

Файлы `script.py`, `script.bat` и `scripts.sh` в исходном архиве пустые. Они не запускают приложение и не выполняют задач.

Когда появится реализация, укажите здесь назначение каждого скрипта, требования к окружению и команды запуска. Не храните в скриптах пароли, токены или другие секреты.
